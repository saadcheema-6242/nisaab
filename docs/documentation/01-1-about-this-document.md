# 1. About This Document

## 1.1 Purpose

This document describes NISAAB from three points of view: how a student uses it, how it is built, and how it is run and maintained. It is meant to be the single reference for the project. A judge should be able to read it to understand what the system does and why it is designed the way it is. A new developer should be able to use it to find their way around the code, the data and the cloud setup. A teacher or student should be able to use the first part without knowing anything about the technology.

## 1.4 Conventions

- `This style` is used for file names, tool names, table names and code.
- SLO codes such as `P-11-B-05` are written exactly as FBISE publishes them.
- "Draft" means a generated item that no subject teacher has reviewed yet. In the current system every item is a draft.
- Numbers in this document come from the working system and its test runs, not from estimates, unless the text says otherwise.
