# 18. Known Limitations

- **The AI can still be wrong inside the syllabus.** Grounding controls scope, not correctness.
- **No teacher has reviewed the question bank.** All 611 examined outcomes hold draft material.
- **Class XII is incomplete.** Only Physics XII is loaded.
- **AI marking is not yet compared with teacher marking.**
- **An internet connection is needed.** There is no offline mode.
- **Compulsory subjects are not included.**
- **The system runs on a free-trial credit that ends in December 2026.**
- **Handwritten answers cannot be marked from photos yet.**
