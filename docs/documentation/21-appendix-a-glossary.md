# Appendix A: Glossary

| Term | Meaning |
|---|---|
| FBISE | Federal Board of Intermediate and Secondary Education, Islamabad. |
| FSc / HSSC | Higher Secondary School Certificate, science groups. Class XI is HSSC-I, Class XII is HSSC-II. |
| NCP 2022-23 | National Curriculum of Pakistan 2022-23, which FBISE papers follow. |
| Assessment Framework | FBISE's published document listing every SLO of a subject with its code, form of assessment and cognitive level. |
| SLO | Student Learning Outcome, with a code such as `P-11-B-05`. |
| Summative / formative / practical | Summative can be examined in theory. Formative is taught but not examined. Practical is assessed in the practical exam. |
| K / U / A | Knowledge, Understanding, Application. |
| MCQ / SRQ / ERQ | Multiple choice, short response and extended response questions. |
| Stimulus set | A scenario with four multiple choice questions based on it. |
| IBCC | Inter Board Committee of Chairmen, which sets the national grading policy. |
| RAG | Retrieval-Augmented Generation. |
| Vector / embedding | A list of numbers that represents the meaning of a piece of text. |
| pgvector | A PostgreSQL extension that stores vectors and compares them. |
| Agent | A model that is given tools and decides which to use and when. |
| LangGraph | A library for building agents as graphs with a typed state. |
| SSE | Server-Sent Events, a way for a server to stream data to the browser. |
| JWKS | JSON Web Key Set, the public keys used to verify sign-in tokens. |
| Mastery | NISAAB's estimate of how well a student knows an outcome. |
| Draft | A generated item not yet reviewed by a teacher. |
